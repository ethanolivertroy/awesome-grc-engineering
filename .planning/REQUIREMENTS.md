# Requirements: Awesome GRC Engineering

**Defined:** 2025-01-26
**Core Value:** Become THE canonical reference the GRC engineering community points to

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Foundation

- [ ] **FOUND-01**: Repository passes awesome-lint validation
- [ ] **FOUND-02**: README follows sindresorhus/awesome structure (title, badge, TOC, categories)
- [ ] **FOUND-03**: GitHub Actions workflow runs awesome-lint on PRs
- [ ] **FOUND-04**: GitHub Actions workflow runs lychee link checker weekly + on PRs
- [ ] **FOUND-05**: doctoc auto-generates table of contents
- [ ] **FOUND-06**: CONTRIBUTING.md documents quality criteria and submission process
- [ ] **FOUND-07**: CODE_OF_CONDUCT.md uses Contributor Covenant
- [ ] **FOUND-08**: LICENSE file uses CC0-1.0 (public domain)
- [ ] **FOUND-09**: Repository has `awesome-list` and `awesome` GitHub topics

### Content - Tools

- [ ] **TOOL-01**: Policy-as-Code section with 5-10 curated tools (OPA, Kyverno, Sentinel, etc.)
- [ ] **TOOL-02**: Security scanners section with 5-10 curated tools (Prowler, Trivy, Checkov, etc.)
- [ ] **TOOL-03**: Open-source GRC platforms section with 3-5 curated tools
- [ ] **TOOL-04**: Evidence automation section with 5-8 curated tools (SBOM, audit logging)
- [ ] **TOOL-05**: Each tool entry includes opinionated commentary on WHY it matters
- [ ] **TOOL-06**: Each tool entry has dual-audience tag (engineer-friendly, GRC-professional-friendly, or both)

### Content - Learning

- [ ] **LEARN-01**: GRC Engineering fundamentals section (manifesto, philosophy resources)
- [ ] **LEARN-02**: Books & courses section with audience labels (GRC→technical vs technical→GRC)
- [ ] **LEARN-03**: Blogs & newsletters section with key practitioner voices
- [ ] **LEARN-04**: Podcasts & videos section with conference talks and episodes
- [ ] **LEARN-05**: Each learning resource has brief description of what you'll learn

### Content - Frameworks

- [ ] **FRAME-01**: SOC 2 section with automation guides and implementation resources
- [ ] **FRAME-02**: NIST frameworks section (CSF, 800-53, OSCAL)
- [ ] **FRAME-03**: FedRAMP section with OSCAL templates and automation resources
- [ ] **FRAME-04**: ISO 27001 section with implementation guides
- [ ] **FRAME-05**: Each framework section includes engineering-focused resources (not just policy)

### Content - Community

- [ ] **COMM-01**: Communities & forums section (Discord, Slack, forums)
- [ ] **COMM-02**: Conferences & events section with GRC engineering relevance
- [ ] **COMM-03**: Related awesome lists section linking complementary resources

### Quality

- [ ] **QUAL-01**: Minimum 50 curated resources total at launch
- [ ] **QUAL-02**: Maximum 100 resources at launch (quality over quantity)
- [ ] **QUAL-03**: No vendor-sponsored or marketing content
- [ ] **QUAL-04**: All resources align with GRC Engineering Manifesto principles
- [ ] **QUAL-05**: All links verified working at launch

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Certification prep materials | Must teach principles, not just pass tests |
| Vendor marketing content | Violates manifesto values, no genuine value |
| Generic security resources | Plenty exist elsewhere, not GRC-engineering specific |
| Legacy/checkbox compliance | Must align with modern GRC engineering thinking |
| People to follow list | Controversial to maintain, deferred to v2 |
| Comprehensive commercial tools | Open-source preference, pragmatic exceptions only in v2 |
